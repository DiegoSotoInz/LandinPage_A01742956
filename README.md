# HAIL MARY Sinaloa 2026 — Landing Page

Repositorio oficial de la landing page estática para el proyecto aeroespacial **HAIL MARY Sinaloa 2026**.

## Contenido del Repositorio
- `index.html`: Estructura principal con el logo horizontal, presentación del proyecto, modelo predictivo y tabla de resultados.
- `styles.css`: Hoja de estilos en modo oscuro (Dark Theme) basada en los tonos azul nocturno, cian eléctrico y tipografía estilizada de la marca.

## Instrucciones para subir a GitHub Pages
1. Sube `index.html` y `styles.css` a la rama principal (`main` o `master`) de tu repositorio en GitHub.
2. Ve a **Settings** > **Pages** en tu repositorio.
3. En **Source**, selecciona `Deploy from a branch` y elige la rama `main` / `root`.
4. Guarda los cambios. Tu sitio web se publicará automáticamente.
