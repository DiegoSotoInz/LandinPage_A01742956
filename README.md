# HAIL MARY — Misión Espacial Sinaloa 2026

Plataforma web oficial de análisis aerodinámico, simulación de trayectoria y telemetría para el proyecto **HAIL MARY** (Equipo 3 • Grupo 102) en **Rocket Tec Sinaloa 2026**.

## Archivos del Repositorio
- `index.html`: Estructura principal con emblemas duales oficiales, cuenta regresiva en vivo, simulador interactivo de trayectoria balística, pestañas de arquitectura de ingeniería y validación telemétrica.
- `styles.css`: Hoja de estilos diseñada bajo la guía de identidad visual oficial de **HAIL MARY** (`#072F70` Deep Blue, `#0751B5` Impulsed Blue, `#469AFF` Sky Blue y `#FFFFFF`).
- `hail_mary_logo.png`: Emblema circular oficial de HAIL MARY.
- `rocket_tec_logo.png`: Emblema oficial de Rocket Tec Sinaloa 2026.

## Despliegue en GitHub Pages
1. Sube `index.html`, `styles.css`, `README.md`, `hail_mary_logo.png` y `rocket_tec_logo.png` directamente a la raíz de la rama `main` de tu repositorio.
2. En **Settings > Pages**, selecciona `Deploy from a branch` (`main` / `/ (root)`).
